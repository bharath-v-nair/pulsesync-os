# PulseSync Life OS

⚡ **Sub-2-Second Micro-Workout & Life Accountability Progressive Web App**

PulseSync Life OS is a zero-cost, local-first, highly responsive Progressive Web App (PWA) engineered to run on **Motorola Edge 50 Pro (144Hz pOLED)** and **MacBook M4 Air (Chrome)**. It solves three high-friction life tracking domains without cognitive overload:

1. **🏋️ MOVE:** Grease the Groove (GTG) half pull-ups, push-ups, fixed 30 kg barbell lifts, and daily 5k walks.
2. **🧠 FOCUS:** Intensive 20-question technical interview preparation queue, C# DSA LeetCode tracker, active-vs-break timebox splitter, and Feynman synthesis.
3. **🛡️ HABITS:** Day bookends (wake/sleep), reading, and private dopamine detox / clean streaks with encrypted root-cause journaling.

## 🛠️ Final Tech Stack
* **View Layer:** React 19 + TypeScript + Vite
* **Styling:** Tailwind CSS v4 + Compositor-driven GPU CSS transforms (`transform: translate3d`)
* **State & Storage:** Local-first (localStorage / IndexedDB) with schema versioning $\rightarrow$ Firebase Firestore (Spark Plan) in Phase 3
* **Mobile Ergonomics:** 48px+ touch targets, `touch-action: manipulation`, 15ms Web Vibration haptics
* **Hosting & CI/CD:** GitHub Actions $\rightarrow$ Azure Static Web Apps (100% Free Tier)
